## Quick Start

From a working Plasma 6 Wayland session:

```bash
bash ~/macos-tahoe-runbook.sh
```

The runbook is idempotent. Re-run it after any crash, update, or manual tweak.

To verify persistence, log out and back in. The `cosmetic-reset.service` re-applies the look automatically.

If the desktop wallpaper is black:

1. Right-click the desktop → **Configure Desktop and Wallpaper**.
2. Set **Wallpaper type** to **Smart Video Wallpaper Reborn**.
3. Add MP4s to `~/Videos` (or `~/Videos/RGB-Wallpapers`) and re-run the runbook.

### First-time / fresh-install

The current workstation already has the WhiteSur assets, Inter font, and layered packages installed. On a fresh SecureBlue image:

1. Layer packages and reboot:

   ```bash
   run0 --empower bash -c '
     rpm-ostree install -y \
       kvantum cmake pkgconf-pkg-config \
       kf6-kcoreaddons-devel kf6-kconfig-devel kf6-kwindowsystem-devel \
       kdecoration-devel qt6-qtbase-devel qt6-qtdeclarative-devel qt6-qtwayland-devel \
       ffmpeg-free
   '
   ```

2. Install WhiteSur icon/GTK/KDE/cursor themes and Inter font (see `.archive/MACOS_TAHOE_SETUP.md`).
3. Run `bash ~/macos-tahoe-runbook.sh`.

## Theme / Panels / Dock

### What you get

| Element | State |
|---------|-------|
| Icons | `WhiteSur-dark` |
| Cursor | `WhiteSur-cursors` |
| Application style / Qt | Kvantum → `WhiteSur-Dark` |
| GTK theme | `WhiteSur-Dark` |
| Font | `Inter` |
| Window decoration | `WhiteSur-dark` Aurorae, left stoplights (`XIA`) |
| Top panel | True-black, 26 px, floating, flush offset 0, left aligned |
| Bottom dock | True-black, floating, centered, 50 px panel / 48 px icons, always visible |
| Display | Never dims, sleeps, or locks |

### Top panel (menu bar)

- **Height:** 26 px (`thickness=26`), **offset:** 0, **floating:** true, **alignment:** left, **opacity:** opaque.
- **Apple logo:** Kickoff uses `icon=start-here` (`~/.local/share/icons/hicolor/scalable/apps/start-here.svg`).
- **Global Menu:** compact view, no icon.
- **System tray:** `org.kde.plasma.systemtray` (converted from `KdeControlStation` by `~/.local/bin/macos-systemtray.py`).
  - Inline items: volume, network, battery, notifications, clipboard.
  - `iconSpacing=1`, `scaleIconsToFit=true`.
- **Clock:** Digital Clock shows date + 12h format.

### Dock

- **Position:** bottom, centered, floating.
- **Size:** 50 px panel, 48 px icons.
- **Behavior:** always visible (`panelVisibility=0`), does not dodge windows.
- **Launchers (left to right):** Finder, Terminal, TextEdit, Settings, Safari, Screenshot, Dolphin3 Canvas, OpenHands, Trash.
- **Grouping:** `separateLaunchers=false` + `launchInPlace=true` so running apps stay on their pinned icon.
- **Launch feedback:** brief dock-button highlight only; no bouncing busy cursor.

### Window management

- **Buttons:** left-side stoplights (`ButtonsOnLeft=XIA`, no buttons on right).
- **Aurorae:** `WhiteSur-dark`, tight title bar (`TitleBorderLeft=62`, `TitleBorderRight=62`, reduced padding/title-edge values).
- **Placement:** `Placement=Centered`; tiling layouts and electric borders are removed.
- **Shortcuts:** tap `Meta` for KRunner; `Alt+Space` also opens KRunner.

## Wallpapers

The desktop uses **Smart Video Wallpaper Reborn** (`luisbocanegra.smart.video.wallpaper.reborn`) to rotate video wallpapers.

### Adding videos

Drop `.mp4` files into `~/Videos` or `~/Videos/RGB-Wallpapers`, then re-run:

```bash
bash ~/macos-tahoe-runbook.sh
```

The runbook auto-discovers every MP4 in `~/Videos/RGB-Wallpapers` and writes a JSON `VideoUrls` list.

OLED fallback clips are generated by `~/.local/bin/tahoe-wallpaper-helper.sh` when `ffmpeg` is available.

### Optimizing large videos

For 4K files, strip audio and cap the bitrate before dropping them in `~/Videos`:

```bash
mkdir -p ~/Videos/optimized
for v in video1 video2 video3; do
  ffmpeg -y -i "$HOME/Videos/${v}.mp4" \
    -an \
    -vf "scale=3840:2160:force_original_aspect_ratio=decrease,fps=30,format=yuv420p" \
    -c:v libx264 -preset faster -crf 28 -movflags +faststart \
    "$HOME/Videos/optimized/${v}.mp4"
done
```

### Black desktop or Plasma crash loop

1. Re-select **Smart Video Wallpaper Reborn** in desktop wallpaper settings.
2. Check `journalctl --user -b` for Qt Multimedia / FFmpeg errors.
3. As a fallback, force the GStreamer backend:

   ```bash
   mkdir -p ~/.config/plasma-workspace/env
   cat > ~/.config/plasma-workspace/env/qt-media-backend.sh <<'EOF'
   #!/bin/bash
   export QT_MEDIA_BACKEND=gstreamer
   EOF
   chmod +x ~/.config/plasma-workspace/env/qt-media-backend.sh
   ```

   Then log out and back in.

To revert to FFmpeg:

```bash
rm ~/.config/plasma-workspace/env/qt-media-backend.sh
```

### Renamed .desktop entries

| App | Menu name | Icon | Launch command |
|-----|-----------|------|----------------|
| Dolphin | Finder | `org.kde.dolphin` | `dolphin %u` |
| Konsole | Terminal | `utilities-terminal` | `konsole --profile "macOS Terminal"` |
| KWrite | TextEdit | `text-editor` | `kwrite %U` |
| System Settings | Settings | `preferences-system` | `env LD_PRELOAD= systemsettings` |
| Spectacle | Screenshot | `spectacle` | `/usr/bin/spectacle` |
| Trivalent | Safari | `safari-dark` | `/usr/bin/trivalent --profile-directory=Default --ozone-platform=wayland --enable-features=UseOzonePlatform --disable-features=WaylandWindowDecorations %U` |
| OpenWebUI | Dolphin3 Canvas | `dolphin3` | starts `open-webui.service` + opens browser |
| OpenHands | OpenHands | `openhands` | starts `openhands.service` + opens browser |
| Trash | Trash | `user-trash` | `dolphin trash:/` |

All overrides live in `~/.local/share/applications/`.

### Finder (Dolphin)

- Dark mode from WhiteSur/Kvantum.
- Default view: icon view (`ViewMode=0`), 64 px icons, previews enabled.
- Single-click to open files.
- Menu bar, status bar, and zoom slider hidden.
- Sidebar icons fixed at 22 px.

### Terminal (Konsole)

- Profile: **macOS Terminal** (`~/.config/konsole/macOS Terminal.profile`).
- Colors: true black background, near-white foreground.
- Font: `Noto Sans Mono 12`.
- Menu bar hidden by default.

### Safari (Trivalent)

- Renamed to **Safari** with a darker compass icon generated from WhiteSur `safari.svg`.
- Launched with `--profile-directory=Default` and Wayland server-side decorations so KWin draws the WhiteSur stoplights.
- `browser.custom_chrome_frame=false` is set in Trivalent preferences.

### Screenshots

- `~/.local/bin/tahoe-screenshot.sh` captures the workspace via KWin's `ScreenShot2` D-Bus interface.
- `~/.local/share/applications/org.kde.spectacle.desktop` declares `X-KDE-DBUS-Restricted-Interfaces=org.kde.KWin.ScreenShot2`, so Spectacle works on Wayland.

### Desktop pilot / automation (optional)

For agent eyes/hands on the GUI, run the root setup script and reboot:

```bash
run0 /var/home/agent-42/workspace/setup-desktop-pilot.sh
```

After reboot, start the pilot:

```bash

```

## AI Services

Local AI stack runs as user systemd services. No API key is required.

| Service | Purpose | Endpoint | Model |
|---------|---------|----------|-------|
| `ollama.service` | Local LLM inference | `http://localhost:11434` | `Dolphin3.0-Llama3.2-8B` |
| `open-webui.service` | Dolphin3 Canvas chat UI | `http://localhost:60808` | via Ollama |
| `openhands.service` | AI coding agent | `http://localhost:60300` | `ollama/Dolphin3.0-Llama3.2-8B` |

### Start / status

```bash
systemctl --user start ollama.service open-webui.service openhands.service
systemctl --user status ollama.service open-webui.service openhands.service
```

## Persistence

`~/.local/bin/cosmetic-reset.sh` is the persistence layer. It runs once per graphical login via `cosmetic-reset.service`.

### How it survives crashes

`~/.local/bin/plasma-id-discover.py` reads `~/.config/plasma-org.kde.plasma.desktop-appletsrc` and discovers current containment/applet IDs. Both `cosmetic-reset.sh` and `~/macos-tahoe-runbook.sh` source these IDs dynamically instead of hard-coding them.

`~/.local/bin/macos-systemtray.py` converts `KdeControlStation` to `org.kde.plasma.systemtray` only when necessary.

If an optional applet is not discovered, scripts skip that config with a warning.

### What gets reapplied at login

- Theme globals: `kdeglobals`, `kwinrc`, `plasmarc`, `Kvantum/kvantum.kvconfig`, GTK settings.
- Panel/dock geometry in `plasma-org.kde.plasma.desktop-appletsrc`.
- System tray conversion and spacing.
- Dolphin/Finder settings in `dolphinrc`.
- Konsole Terminal profile and colors.
- `.desktop` overrides and custom icons.
- Power/lock settings.
- Aurorae stoplight bar width.
- WhiteSur panel SVG true-black patch.

### Keep it in sync

If you change any of the above manually, mirror the change in `~/macos-tahoe-runbook.sh` and `~/.local/bin/cosmetic-reset.sh` so it survives the next login.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Black desktop, no video | Re-select **Smart Video Wallpaper Reborn** in wallpaper settings. |
| Icons not updated | Run `gtk-update-icon-cache -f ~/.local/share/icons/hicolor` then relogin. |
| Dock still hides | Re-run `~/macos-tahoe-runbook.sh`; verify `panelVisibility=0`. |
| Trivalent has no stoplights | Check it launches with `--ozone-platform=wayland --disable-features=WaylandWindowDecorations` and `custom_chrome_frame=false`. |
| OpenWebUI asks for API key | Ensure Ollama is running; OpenWebUI defaults to local Ollama with no key. |
| Apps open on the right side of the screen | `kwinrc` should not contain `[Tiling]` sections and should have `[Windows] Placement=Centered`. |
| Cursor bounces instead of dock icon | `klaunchrc` should have `BusyCursor=false`, `Bouncing=false`, `TaskbarButton=true`. |
| Spectacle says "not authorized" | `~/.local/share/applications/org.kde.spectacle.desktop` must contain `X-KDE-DBUS-Restricted-Interfaces=org.kde.KWin.ScreenShot2`. |
| Wallpaper flickers / Plasma crashes | Try the GStreamer backend (see [Wallpapers](#wallpapers)). |
| Top panel is gray, not black | WhiteSur panel SVGs were not patched; re-run `~/macos-tahoe-runbook.sh`. |
| System tray is KdeControlStation | Run `python3 ~/.local/bin/macos-systemtray.py --restart`. |
| cosmetic-reset.service fails | Run `systemctl --user status cosmetic-reset.service`; fix the error, update the script, then `systemctl --user daemon-reload && systemctl --user restart cosmetic-reset.service`. |

## Bootable USB overlay

A self-contained bootable image is built by `~/.local/bin/tahoe-usb-backup.sh`.

Staging directory:
`~/.tahoe-usb-staging/`

Key files:
- `secureblue-kinoite-nvidia-open-hardened.iso` — SecureBlue Kinoite installer
- `tahoe-backup.tar.zst` — compressed user-space cosmetic overlay
- `tahoe-restore.sh` — restore script to run after installation
- `tahoe-usb.img` — complete bootable raw disk image

Flash the image to a USB drive (replace `/dev/sdX` with the correct device):

```bash
run0 dd if="$HOME/.tahoe-usb-staging/tahoe-usb.img" of=/dev/sdX bs=4M status=progress conv=fsync
```

After installing from the USB and logging in:

```bash
bash /run/media/$USER/TAHOE/tahoe/tahoe-restore.sh
```

To write directly to a USB device instead of creating an image:

```bash
run0 bash "$HOME/.local/bin/tahoe-usb-backup.sh" /dev/sdX
```

Limitations:
- The backup does **not** include layered system packages, `~/.local/venvs`, or `~/.local/src`.
- Trivalent's in-window menu bar cannot be hidden because `appmenu-gtk-module` is not available in the SecureBlue repos.

## Private Git backup

`~/.local/bin/tahoe-git-export.sh` keeps a local-only Git repository of the tracked Tahoe configuration.

- Working tree: `~/.tahoe-config`
- Bare repo: `~/.tahoe-config.git`

Run it after any manual cosmetic change:

```bash
bash "$HOME/.local/bin/tahoe-git-export.sh"
```

Nothing is sent to the internet.
